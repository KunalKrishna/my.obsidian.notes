### ✅ **Global Skills WORK (Both CLI & VS Code Extension)**
You can create skills in `%USERPROFILE%\.claude\skills` and they'll be available everywhere
```
C:\Users\YourName\
├── .claude\
│   └── skills\
│       ├── update-readme\
│       │   └── SKILL.md         ← Available in ALL projects ✅
│       └── sync-docs\
│           └── SKILL.md          ← Available in ALL projects ✅
```
